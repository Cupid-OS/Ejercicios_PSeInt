# Ejercicios de PSeInt

Colección de ejercicios de pseudocódigo resueltos en PSeInt. Cada archivo `.psc` contiene un
algoritmo independiente y lleva el enunciado como comentario en la primera línea.

Autor: Thiago Montblanch Mota (Cupid-OS)

## Contenido

| Carpeta | Ejercicios | Tema |
| --- | --- | --- |
| `Condicionales` | 40 | Condicionales simples, compuestas, anidadas y deducción de supuestos |
| `Pseudocodigo_01` | 20 | Operaciones básicas, conversiones de unidades y tablas de multiplicar |
| `Bucles` | 14 | Bucle Mientras, Repetir-Hasta y Para (incluidos bucles anidados) |

Total: 74 programas.

## Cómo abrir los ejercicios

1. Abrir PSeInt.
2. `Archivo > Abrir` y seleccionar el archivo `.psc`.
3. Ejecutar con `F9` o el botón de ejecutar.

Los archivos están guardados en UTF-8.
